1. StackGuard (server + dashboard) deployed to namespace {{ include "stackguard.namespace" . }}.
   Monolithic: exactly 1 pod each for server, dashboard, Postgres and Valkey (no autoscaling).

2. Wait for pods:
   kubectl get pods -n {{ include "stackguard.namespace" . }} -w

3. Public services:
   kubectl get svc -n {{ include "stackguard.namespace" . }} stackguard-server stackguard-dashboard

4. Current URLs (set urls.api / urls.dashboard, or on AKS <component>.service.azureDnsLabel
   with global.azureRegion, then upgrade the release):
   API:       {{ include "stackguard.publicUrl" (dict "ctx" . "url" .Values.urls.api "service" .Values.server.service) }}
   Dashboard: {{ include "stackguard.publicUrl" (dict "ctx" . "url" .Values.urls.dashboard "service" .Values.dashboard.service) }}

5. After changing URLs, restart the workloads:
   kubectl rollout restart deployment/stackguard-server deployment/stackguard-dashboard -n {{ include "stackguard.namespace" . }}

6. Open the dashboard URL in the browser. API webhooks use the API URL.
